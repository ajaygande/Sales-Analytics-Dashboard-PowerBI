# Data

This folder contains the source dataset used for the AdventureWorks Sales Dashboard.

## Dataset

**Name:** AdventureWorks Sales Sample
**Source:** Microsoft Official Sample Data
**Format:** Excel (.xlsx)
**Download:** [AdventureWorks Sales Sample](https://github.com/microsoft/powerbi-desktop-samples/blob/main/AdventureWorks%20Sales%20Sample/AdventureWorks%20Sales.xlsx)

## Tables Included

| Table | Type | Description |
|---|---|---|
| Sales | Fact | Main sales transactions |
| SalesOrder | Fact | Order level details |
| Customer | Dimension | Customer demographics |
| Product | Dimension | Product details and pricing |
| Date | Dimension | Calendar and fiscal periods |
| Reseller | Dimension | Reseller channel information |
| SalesTerritory | Dimension | Geographic sales territories |
